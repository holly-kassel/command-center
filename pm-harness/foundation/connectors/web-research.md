# Connector: Web Research

**Status:** connected (public web only). **Use for:** external context — market, competitors,
standards, prior art, definitions.

## What to pull it for

- **SHAPE:** prior art and comparable solutions when framing an outcome (show-don't-tell examples).
- **ALIGN:** external validation or contrast for a POV; competitive/landscape context.

## Using it well

- **Public sources only.** Never send internal/confidential content (code, customer data,
  unreleased plans) to the web.
- Cite as `[web: <domain>]` with enough specificity that the operator can re-find it.
- Prefer primary/authoritative sources; note when something is opinion vs. established fact.

## Graceful failure

- Unreachable or thin results → flag it; don't present speculation as sourced fact. External context
  is a supporting leg, never a substitute for customer + data evidence.
